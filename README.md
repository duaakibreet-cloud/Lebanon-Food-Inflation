# Lebanon's Food Inflation Crisis

This Streamlit app explores changes in food prices in Lebanon from 2000 to 2023 and compares them with changes in the Lebanese pound.

## Features

- Interactive year-range selection
- Interactive month selection
- Food price visualization over time
- Comparison between food prices and the Lebanese pound
- Key insights about Lebanon's food inflation crisis

## Data

The application uses food CPI and exchange-rate data for Lebanon.
